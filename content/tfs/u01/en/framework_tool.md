# Framework — Fast vs. Slow Decision Check Canvas

Use in workshop or print for the floor. Run one canvas per decision you are unsure about before you act.

## 1. The call (one sentence)

What decision am I about to make, right now?

## 2. Speed check

| Trigger | Present? (yes/no) | Why |
| --- | --- | --- |
| Novelty — does this differ from cases I have truly handled before? | | |
| Stakes — is a wrong call costly, hard to reverse, or safety-related? | | |
| Conflicting signals — does my instinct disagree with the data in front of me? | | |

## 3. Route decision

- **Zero triggers present:** Proceed on fast judgment. Note it and move on.
- **One trigger present:** Take the short structured check below before acting.
- **Two or more triggers present:** Full check required; escalate if you cannot resolve it in the time available.

## 4. Structured check (when required)

1. What specific evidence would confirm this matches a pattern I have handled before?
2. What is the one source I have not looked at yet (log, second tab, prior shift note)?
3. Who else has seen this exact situation, and what did they see?

## 5. Visibility

Where does the team see that a check happened (board, radio call, log entry)?

## 6. Owner when you are off-shift

Name + backup, so the check does not disappear when you are not there:

## 7. After-action note

What made this call fast-worthy or slow-worthy? Add one line to the shift log either way.

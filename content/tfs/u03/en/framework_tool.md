# Framework — Base-Rate & Sample-Check Canvas for Floor Calls

Use in workshop or print for the floor. Run one canvas per unusual number before you act on it or explain it.

## 1. The number (one sentence)

What result am I reacting to, and what decision does it drive?

## 2. Sample check

| Trigger | Present? (yes/no) | Why |
| --- | --- | --- |
| Small sample — is this based on a handful of units, one shift, or one person? | | |
| Record result — is this the best or worst result on record for this line, person, or station? | | |
| Ready-made story — does a cause already feel obvious before I have checked the baseline? | | |

## 3. Route decision

- **Zero triggers present:** Act on the number. Note it and move on.
- **One trigger present:** Run the structured check below before acting or explaining.
- **Two or more triggers present:** Full check required; hold the verdict until you have a second data point or the baseline comparison.

## 4. Structured check (when required)

1. What is the trailing baseline or historical rate for this exact line, station, or person?
2. Could a sample this size produce this result by chance alone, with no real change underneath it?
3. If I expect a pull-back toward normal next period, what would that look like—and am I ready to not treat it as a new problem?
4. Does the base rate for this kind of swing explain it, before I accept the first causal story offered?

## 5. Visibility

Where does the team see that the check happened (board, log entry, ops-review note)?

## 7. After-action note

Did the next data point confirm a real shift, or a pull-back toward normal? Add one line to the shift log either way.

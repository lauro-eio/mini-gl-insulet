# Marco — Lienzo de tasa base y verificación de muestra para decisiones de piso

Usa esto en el taller o impreso para el piso. Corre un lienzo por cada número inusual antes de actuar sobre él o explicarlo.

## 1. El número (una oración)

¿A qué resultado estoy reaccionando, y qué decisión impulsa?

## 2. Verificación de muestra

| Disparador | ¿Presente? (sí/no) | Por qué |
| --- | --- | --- |
| Muestra pequeña — ¿esto se basa en un puñado de unidades, un turno o una persona? | | |
| Resultado récord — ¿este es el mejor o peor resultado registrado para esta línea, persona o estación? | | |
| Historia ya lista — ¿una causa ya se siente obvia antes de haber verificado la línea base? | | |

## 3. Decisión de ruta

- **Cero disparadores presentes:** Actúa sobre el número. Anótalo y sigue adelante.
- **Un disparador presente:** Corre la verificación estructurada de abajo antes de actuar o explicar.
- **Dos o más disparadores presentes:** Se requiere verificación completa; retén el veredicto hasta tener un segundo dato o la comparación de línea base.

## 4. Verificación estructurada (cuando se requiere)

1. ¿Cuál es la línea base o tasa histórica para esta línea, estación o persona exacta?
2. ¿Podría una muestra de este tamaño producir este resultado solo por azar, sin ningún cambio real detrás?
3. Si espero un retroceso hacia lo normal en el próximo periodo, ¿cómo se vería eso—y estoy listo para no tratarlo como un problema nuevo?
4. ¿La tasa base para este tipo de oscilación lo explica, antes de que acepte la primera historia causal ofrecida?

## 5. Visibilidad

¿Dónde ve el equipo que la verificación ocurrió (pizarra, entrada de registro, nota de revisión de operaciones)?

# Framework — Bias Check Canvas for Floor Decisions

Use in workshop or print for the floor. Run one canvas per decision you are unsure about before you commit.

## 1. The call (one sentence)

What decision am I about to make, right now?

## 2. Bias check

| Shortcut | Present? (yes/no) | Why |
| --- | --- | --- |
| Ease — am I trusting this because it reads smoothly, not because I checked it? | | |
| Anchor — is a number or claim I heard first pulling my estimate, regardless of its source? | | |
| Availability — is a vivid or recent case making this feel more common than it actually is? | | |
| Representativeness — does this case just resemble a known pattern, without a matching base rate? | | |

## 3. Route decision

- **Zero shortcuts present:** Proceed on your read. Note it and move on.
- **One shortcut present:** Run the matching structured check below before acting.
- **Two or more present:** Full check required; escalate if you cannot resolve it in the time available.

## 4. Structured check (when required)

1. **Ease:** What evidence backs this beyond how clean or familiar it looks?
2. **Anchor:** What is the actual source figure, separate from the first number spoken?
3. **Availability:** What is the real rate over recent months, not just what comes to mind fastest?
4. **Representativeness:** What is the base rate for this category, and does this case truly match it or only resemble it?

## 5. Visibility

Where does the team see that a check happened (board, radio call, log entry)?

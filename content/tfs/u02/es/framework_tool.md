# Marco — Lienzo de verificación de sesgos para decisiones de piso

Úsalo en el taller o imprímelo para el piso. Corre un lienzo por cada decisión sobre la que tengas dudas antes de comprometerte.

## 1. La decisión (una frase)

¿Qué decisión estoy por tomar, en este momento?

## 2. Verificación de sesgos

| Atajo | ¿Presente? (sí/no) | Por qué |
| --- | --- | --- |
| Facilidad — ¿confío en esto porque se lee con fluidez, no porque lo verifiqué? | | |
| Anclaje — ¿un número o afirmación que escuché primero está arrastrando mi estimación, sin importar su fuente? | | |
| Disponibilidad — ¿un caso vívido o reciente está haciendo que esto se sienta más común de lo que realmente es? | | |
| Representatividad — ¿este caso solo se parece a un patrón conocido, sin una tasa base que lo respalde? | | |

## 3. Decisión de ruta

- **Cero atajos presentes:** Avanza con tu lectura. Anótalo y sigue adelante.
- **Un atajo presente:** Corre la verificación estructurada correspondiente de abajo antes de actuar.
- **Dos o más presentes:** Se requiere verificación completa; escala si no puedes resolverla en el tiempo disponible.

## 4. Verificación estructurada (cuando se requiere)

1. **Facilidad:** ¿qué evidencia respalda esto más allá de lo limpio o familiar que se ve?
2. **Anclaje:** ¿cuál es la cifra real de la fuente, separada del primer número dicho?
3. **Disponibilidad:** ¿cuál es la tasa real de los últimos meses, no solo lo que viene más rápido a la mente?
4. **Representatividad:** ¿cuál es la tasa base para esta categoría, y este caso realmente coincide con ella o solo se le parece?

¿Dónde ve el equipo que la verificación ocurrió (tablero, llamada de radio, entrada de bitácora)?

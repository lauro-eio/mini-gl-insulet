# Framework — Team Habit Loop Redesign Canvas

Use in workshop or print for the floor. Complete one canvas per unwanted behavior you will redesign this month.

## 1. Target behavior

What exact behavior do you want to change? (Observable, not a character judgment.)

## 2. Map the current loop

| Element | Current loop |
| --- | --- |
| Cue (specific, observable trigger) | |
| Craving (the want it activates) | |
| Response (exact current behavior) | |
| Reward (what reinforces it today) | |

## 3. What stays the same

Which cue and craving will you keep, because removing them isn't realistic on this floor?

## 4. Redesigned response

What new behavior satisfies the same craving, tied to the same cue, while serving the team goal?

## 5. Redesigned reward

What fires fast and visibly the moment the new response happens—fast enough to outcompete the old reward?

## 6. Friction to remove

What tool, script, or approval step makes the new response harder than the old one right now?

## 7. Owner and visibility

Who confirms the new loop ran today, and where is that visible to the team?

## 8. Relapse plan

If the old response reappears once, what will you say and do—without restarting from zero?

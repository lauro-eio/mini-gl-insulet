# Key Notes — Mapping and Redesigning the Team Habit Loop

**Unit goal:** Map the loop behind an unwanted floor behavior and redesign it into something goal-aligned—one you can coach even when you are not watching.

## Core ideas

- **The loop:** Cue → craving → response → reward. All four are always present, whether you named them or not.
- **Cue:** The specific, observable trigger already on the shift (a red number, a hard call, a backlog).
- **Craving:** The felt want the cue activates—often relief, belonging, or looking competent, not the behavior itself.
- **Response is the easiest lever to change, but never the only one:** blocking it without meeting the craving invites relapse or a worse workaround.
- **Reward must arrive fast and visibly**, or the redesigned response loses to the old one by default.

## Frontline leader checklist

1. Pick one unwanted behavior you can observe directly this week.
2. Write its loop in one line each: cue, craving, response, reward.
3. Ask what the response is actually buying the person—not what rule it breaks.
4. Design a new response tied to the **same cue**, satisfying the **same craving**, that serves the team goal.
5. Attach a fast, visible reward to the new response before you remove the old one.
6. Expect the old response to reappear once; treat it as data, not defiance.
7. Coach the loop with the person, out loud, so they can run it without you present.

## Reflection

Which unwanted behavior on your floor keeps "coming back" no matter how many times you've corrected it—and what is it quietly rewarding?

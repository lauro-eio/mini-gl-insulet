# Marco — Lienzo de rediseño del bucle de hábito del equipo

Úsalo en el taller o imprímelo para el piso. Completa un lienzo por cada conducta no deseada que rediseñarás este mes.

## 1. Conducta objetivo

¿Qué conducta exacta quieres cambiar? (Observable, no un juicio de carácter.)

## 2. Mapea el bucle actual

| Elemento | Bucle actual |
| --- | --- |
| Clave (disparador específico y observable) | |
| Anhelo (el deseo que activa) | |
| Respuesta (conducta actual exacta) | |
| Recompensa (qué la refuerza hoy) | |

## 3. Qué se mantiene igual

¿Qué clave y anhelo mantendrás, porque eliminarlos no es realista en este piso?

## 4. Respuesta rediseñada

¿Qué nueva conducta satisface el mismo anhelo, atada a la misma clave, mientras sirve a la meta del equipo?

## 5. Recompensa rediseñada

¿Qué se activa rápido y de forma visible en el momento en que ocurre la nueva respuesta—lo bastante rápido para vencer a la vieja recompensa?

## 6. Fricción a quitar

¿Qué herramienta, script o paso de aprobación hace que la nueva respuesta sea más difícil que la vieja en este momento?

## 7. Dueño y visibilidad

¿Quién confirma que el nuevo bucle corrió hoy, y dónde es visible eso para el equipo?

## 8. Plan de recaída

Si la vieja respuesta reaparece una vez, ¿qué dirás y harás—sin reiniciar desde cero?

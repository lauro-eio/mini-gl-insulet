# Framework — Frontline Cue & Environment Redesign Canvas

Use in workshop or print for the floor. Run the scorecard first, then redesign one habit at a time.

## 1. Habits scorecard

List five current team or personal floor habits. Mark each Helpful (H) or Harmful (X).

## 2. Pick one harmful habit

Which one habit will you redesign first, and why this one?

## 3. Name the cue

What exact thing triggers it—place, object, time of day, person, sound?

## 4. Make it conscious

What will someone say or point to out loud, right when the cue appears, so it stops being automatic?

## 5. Redesign the environment

What will you move, remove, relabel, or reorder so the helpful response becomes the easier path?

## 6. Visibility

Where will the scorecard and the change live so the team can see and reinforce it (board / shift card / checklist)?

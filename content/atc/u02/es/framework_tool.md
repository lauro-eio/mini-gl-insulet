# Marco — Lienzo de identidad del equipo: Votos diarios

Úsalo en el taller o imprímelo para el piso. Completa un lienzo por cada identidad que quieras construir en tu equipo este mes.

## 1. Identidad aspiracional

"Somos el tipo de equipo que ________."

## 2. Auditoría de evidencia

| Pregunta | Tus notas |
| --- | --- |
| ¿Qué ya demuestra que esta identidad es cierta? | |
| ¿Qué la contradice ahora mismo (un atajo, un número inflado, un paso saltado)? | |

## 3. El voto de hoy

¿Qué acción pequeña y visible este turno cuenta como evidencia de la identidad? (Menos de 5 minutos, hecha por el equipo, no solo descrita.)

## 4. Chequeo de capas

| Capa | Tu diseño |
| --- | --- |
| Resultado (lo que queremos lograr) | |
| Proceso (el paso que lo produce) | |
| Identidad (la frase que el proceso demuestra) | |

## 5. Visibilidad

¿Dónde ve u oye el equipo que se refuerza la identidad (línea del stand-up, tablero, nota de traspaso)?

## 6. Inducción de un nuevo integrante

¿Cómo aprenderá un nuevo integrante esta identidad en la primera semana—quién la narra, y qué observa, no solo qué lee?

## 7. Prueba de presión

Nombra una situación este mes (pedido urgente, mal turno, falta de personal) que probablemente ponga a prueba esta identidad. ¿Qué coacharás al equipo para proteger primero?

## 8. Revisión de viernes

Mantener / ajustar / soltar el voto—y una frase para tu gerente que describa la identidad en lenguaje de resultado, no en lenguaje blando.

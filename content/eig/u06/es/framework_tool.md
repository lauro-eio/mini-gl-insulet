# Marco — Lienzo de reparación de confianza: nombrar la ruptura antes de repararla

Úsalo en el taller o imprímelo para el piso. Corre un lienzo por cada momento de fricción antes de responder a él.

## 1. La fricción (una frase)

¿Qué acaba de pasar, y cuál es la tensión en este momento?

## 2. Diagnóstico: ¿tarea o confianza?

- **Solo tarea:** Avanza—aborda el desacuerdo de trabajo directamente; no se necesita reparación más allá de resolver el punto.
- **Confianza involucrada:** Continúa al paso 3.

## 3. ¿Qué pata se tambaleó?

| Pata | ¿Presente? (sí/no) | Por qué |
| --- | --- | --- |
| Capacidad — ¿duda de que esta persona (o tú) pueda hacer el trabajo? | | |
| Benevolencia — ¿duda de que esta persona le quiera bien? | | |
| Integridad — ¿duda de que esta persona dijera la verdad o cumpliera su palabra? | | |

## 4. Ruta de reparación

- **Tambaleo de capacidad:** Disculpa más una corrección concreta, luego una repetición demostrada con apoyo visible.
- **Tambaleo de benevolencia:** Nombra directamente la pregunta sobre la intención y pregunta qué demostraría que realmente te importó.
- **Tambaleo de integridad:** Una disculpa por sí sola no cerrará esto. Comprométete a un comportamiento específico y verificable, sostenido durante un número determinado de turnos.

## 5. Visibilidad

¿Dónde ve la cuadrilla que la reparación ocurrió—no solo escucha que se discutió?

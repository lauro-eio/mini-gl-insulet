# Role-play estratégico — Asegurar una norma de reparación de confianza tras un error público

**Duración:** 40–50 minutos
**Propósito:** Practicar asegurar el respaldo para una práctica nombrada y basada en criterios de reparación de confianza, después de que un error se volviera visible para más de un turno.

## Cuatro roles

1. **Supervisor (protagonista):** Quiere aprobación para una práctica permanente: toda ruptura de confianza se diagnostica según qué pata se tambaleó—capacidad, benevolencia o integridad—antes de elegir y registrar una reparación.
2. **Gerente de operaciones enfocado en velocidad (antagonista):** Medido por rendimiento; ve las conversaciones de reparación como tiempo perdido y llama a la práctica "pensar de más un error que ya está corregido".
3. **Analista de calidad o seguridad (escéptico):** Apoya la idea en principio pero necesita criterios nombrados para lo que cuenta como ruptura de confianza frente a fricción rutinaria, además de un límite de tiempo claro para cuánto debería tomar una reparación.
4. **Supervisor par (aliado o indeciso):** Apoyará la práctica si no convierte cada pequeño desacuerdo en un proceso formal de reparación, y si no se convierte en silencio en una forma de evitar conversaciones directas.

## Tesis del conflicto

¿Puede el supervisor proteger una práctica de reparación nombrada, que diagnostica primero, para rupturas de confianza genuinas, sin verse débil ante el gerente de operaciones o vago ante el analista?

## Señales de éxito

- Patas de confianza nombradas (capacidad, benevolencia, integridad), no un genérico "hablemos de sentimientos"
- Una línea clara entre la fricción rutinaria de tarea y una ruptura de confianza real
- Un límite de tiempo fijo para la reparación, acordado de antemano
- Un registro visible de cuándo se usó la práctica y qué cambió

## Preguntas para el debrief

1. ¿Qué argumento aterrizó con el gerente de operaciones frente al analista?
2. ¿Cómo convirtió el supervisor "diagnosticar antes de reparar" en un lenguaje que se lee como control de riesgo, no como debilidad?
3. ¿Qué haría que la práctica desapareciera en silencio durante la próxima semana de crisis—y quién es responsable de prevenirlo?

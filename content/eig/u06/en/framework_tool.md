# Framework — Trust Repair Canvas: Naming the Break Before You Patch It

Use in workshop or print for the floor. Run one canvas per moment of friction before you respond to it.

## 1. The friction (one sentence)

What just happened, and what is the tension right now?

## 2. Diagnose: task or trust?

- **Task only:** Proceed—address the work disagreement directly; no repair needed beyond resolving the point.
- **Trust involved:** Continue to step 3.

## 3. Which leg wobbled?

| Leg | Present? (yes/no) | Why |
| --- | --- | --- |
| Ability — do they doubt this person (or you) can do the job? | | |
| Benevolence — do they doubt this person means well toward them? | | |
| Integrity — do they doubt this person told the truth or kept their word? | | |

## 4. Repair route

- **Ability wobble:** Apology plus a concrete fix, then one demonstrated rep with visible support.
- **Benevolence wobble:** Name the intent question directly and ask what would show you actually cared.
- **Integrity wobble:** An apology alone will not close this. Commit to a specific, verifiable behavior, sustained over a set number of shifts.

## 5. Visibility

Where does the crew see that the repair happened—not just hear that it was discussed?

## 7. After-action note

What would have surfaced this friction earlier—before it needed a repair at all? Add one line to the shift log either way.

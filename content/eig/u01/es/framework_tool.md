# Marco — Lienzo de verificación de señal: nombrar el impulso antes de decidir

Úsalo en el taller o imprímelo para el piso. Corre un lienzo por cada momento en que notes un impulso emocional fuerte antes de actuar sobre él.

## 1. El momento (una frase)

¿Qué acaba de pasar, y qué estoy sintiendo en este momento?

## 2. Verificación de señal

| Disparador | ¿Presente? (sí/no) | Por qué |
| --- | --- | --- |
| Desajuste de intensidad — ¿este sentimiento parece más grande de lo que la situación justifica? | | |
| Decisión de por medio — ¿está por salir de mi boca una decisión que afecta al equipo? | | |
| Propagación visible — ¿mi rostro, voz o postura ya le están mostrando esto a otros? | | |

## 3. Decisión de ruta

- **Cero disparadores presentes:** Avanza. La señal es proporcional; actúa y sigue adelante.
- **Un disparador presente:** Haz la etiqueta y verificación breve de abajo antes de hablar o actuar.
- **Dos o más disparadores presentes:** Se requiere una pausa completa; delega la siguiente llamada de radio o instrucción si no puedes tomarla.

## 4. Etiqueta y verificación (cuando se requiere)

1. Nombra el sentimiento en una o dos palabras (por ejemplo, "ira defensiva", "miedo de sobresalto").
2. ¿Qué pasó realmente, aparte de lo que estoy sintiendo al respecto?
3. ¿Cuál es la única pregunta que podría hacer en lugar de la afirmación que quiero hacer?

## 5. Visibilidad

¿Dónde ve el equipo que tomaste la pausa (un silencio, una frase, una llamada de radio)?

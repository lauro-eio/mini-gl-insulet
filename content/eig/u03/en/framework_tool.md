# Framework — State Check Canvas: Naming Your State Before You Coach

Use in workshop or print for the floor. Run one canvas per coaching conversation you know will matter, before you start it.

## 1. The conversation (one sentence)

Who am I about to coach, and what is the actual issue I need to raise?

## 2. State check

| Trigger | Present? (yes/no) | Why |
| --- | --- | --- |
| Carryover — is a charge from an earlier, unrelated moment still running? | | |
| Record attached — will this conversation be documented, or affect rating, schedule, or standing? | | |
| Blurred target — can I clearly say this feeling is about this report's performance, not something else? | | |

## 3. Route decision

- **Zero triggers present:** Proceed. Your state is likely proportionate to this conversation.
- **One trigger present:** Take the short label-and-check below before you start.
- **Two or more triggers present:** Full check required; reschedule ten minutes if you cannot take it now.

## 4. Label-and-check (when required)

1. Name the feeling in one or two specific words (e.g., "residual frustration," "disappointment," "worry about being blamed")—not a vague "upset."
2. What actually happened with this report, separate from what I am currently feeling about it?
3. What is the one question I could open with instead of the verdict I want to deliver?

## 5. Visibility

How will you know, in the moment, that your opening line matches the actual issue and not your mood walking in?

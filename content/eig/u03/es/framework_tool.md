# Marco — Lienzo de verificación de estado: nombrar tu estado antes de dar coaching

Úsalo en el taller o imprímelo para el piso. Corre un lienzo por cada conversación de coaching que sepas que va a importar, antes de empezarla.

## 1. La conversación (una frase)

¿A quién estoy por dar coaching, y cuál es el problema real que necesito plantear?

## 2. Verificación de estado

| Disparador | ¿Presente? (sí/no) | Por qué |
| --- | --- | --- |
| Arrastre — ¿una carga de un momento anterior, no relacionado, sigue activa? | | |
| Registro asociado — ¿esta conversación se documentará, o afecta la calificación, el horario o la posición del colaborador? | | |
| Blanco confuso — ¿puedo decir con claridad que este sentimiento tiene que ver con el desempeño de este colaborador, no con otra cosa? | | |

## 3. Decisión de ruta

- **Cero disparadores presentes:** Avanza. Tu estado probablemente es proporcional a esta conversación.
- **Un disparador presente:** Haz la etiqueta y verificación breve de abajo antes de empezar.
- **Dos o más disparadores presentes:** Se requiere una verificación completa; reprograma diez minutos si no puedes tomarla ahora.

## 4. Etiqueta y verificación (cuando se requiere)

1. Nombra el sentimiento en una o dos palabras específicas (por ejemplo, "frustración residual," "decepción," "preocupación de que me culpen")—no un vago "molesto."
2. ¿Qué pasó realmente con este colaborador, aparte de lo que estoy sintiendo al respecto?
3. ¿Cuál es la única pregunta con la que podría abrir en lugar del veredicto que quiero dar?

## 5. Visibilidad

¿Cómo sabrás, en el momento, que tu frase de apertura coincide con el problema real y no con el ánimo con el que entraste?

## 7. Nota de cierre

¿Tu frase de apertura le pertenecía a este colaborador o a otra cosa? Agrega una línea a tu registro de coaching en cualquiera de los dos casos.

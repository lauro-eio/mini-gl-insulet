# Marco — Mapa de integración: los tres puntos de contacto donde la habilidad se queda o se desvanece

Úsalo en el taller o imprímelo para el piso. Corre esto una vez por cada punto de contacto que quieras construir o reparar.

## 1. El punto de contacto (elige uno)

¿En qué momento estoy integrando la habilidad: la inducción de nuevos integrantes, el coaching en el huddle previo al turno, o un check-in entre pares después de un incidente?

## 2. Verificación del estado actual

| Pregunta | Sí/No | Por qué |
| --- | --- | --- |
| ¿Este punto de contacto ocurre actualmente, aunque sea de forma informal? | | |
| ¿Ocurre de la misma manera esté yo en turno o no? | | |
| ¿Un nuevo integrante o compañero lo describiría como normal, no como remedial? | | |

## 3. Decisión de diseño

- **No está ocurriendo en absoluto:** Diseña la versión más pequeña que podría correr esta semana (un check-in de dos minutos, una frase modelada en el huddle, una conversación entre pares opcional).
- **Ocurre pero depende de mí:** Nombra un segundo responsable y delega una instancia este mes.
- **Ocurre y tiene responsable:** Fija una fecha de revisión y verifica si sigue aterrizando como se pretendía.

## 4. Constrúyelo (llena esto para el punto de contacto que elegiste)

1. ¿Qué pasa exactamente, en una frase (quién dice o hace qué, y cuándo)?
2. ¿Quién es responsable si estoy fuera de turno?
3. ¿Cómo aprende un nuevo integrante o compañero que esto es normal, no un programa especial?

## 5. Visibilidad

¿Dónde ve el equipo que este punto de contacto ocurre—para que se lea como práctica estándar, no como un anuncio de una sola vez?

## 6. Salvaguarda

¿Qué haría que este punto de contacto se detuviera en silencio durante la próxima temporada de mucha carga, y qué lo protege cuando eso pasa?

## 7. Nota de cierre

Un mes a partir de ahora: ¿este punto de contacto funcionó como se diseñó, se desvió, o desapareció? Agrega una línea a tu registro en cualquiera de los casos.

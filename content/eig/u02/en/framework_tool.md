# Framework — Hijack Interrupt Card: Getting the High Road Back Before You Decide

Use in workshop or print for the floor. Run this card the moment you suspect a hijack is already active — not a mild surge, but a locked-in reaction already steering you.

## 1. The moment (one sentence)

What is happening right now, and what am I about to do because of it?

## 2. Marker check

| Marker | Present? (yes/no) | Why |
| --- | --- | --- |
| Working memory drop — can I restate the last real instruction or detail, word for word? | | |
| Options collapsed — is the same one move surfacing regardless of what I actually know? | | |
| Recovery lag — has this reaction outlasted whatever triggered it by more than a few seconds? | | |

## 3. Route decision

- **Zero markers present:** Proceed. This is a proportionate reaction, not an active hijack.
- **One marker present:** Run the interrupt below before you act.
- **Two or more markers present:** Full interrupt required; hand the next decision to someone else if you cannot complete it first.

## 4. The interrupt

1. Say the state out loud: "I'm locked on one move here."
2. Ask yourself one question you cannot fake an answer to (e.g., "What were the last two checks on this?").
3. If you cannot answer it, that gap is your evidence the hijack is still running — get the answer before acting.

## 5. Visibility

How does your team see that you ran the interrupt (a phrase, a pause, a question asked out loud)?

Name + backup, so a peer can flag a hijack in progress even when you are not there to catch your own:

## 7. After-action note

Which marker showed first, and did the interrupt actually change the call? One line either way, in the shift log.
